# MAISON & FORM — Furniture storefront concept

A responsive, single-file luxury furniture e-commerce portfolio demo.

## Preview
Open `index.html` in a browser, or deploy the folder to a static hosting provider such as GitHub Pages.

## Included
- Responsive homepage and collections
- Searchable and filterable product catalogue
- Wishlist toggles
- Shopping cart with quantity controls and local storage
- Simulated checkout preview

## Important
This is a **portfolio concept**, not a functioning WooCommerce store. Products, prices, and brand are illustrative. Checkout does not collect payment or place orders. Product photographs load from Unsplash and require an internet connection. Verify image licenses and replace images with brand-owned assets before any commercial launch.

## Production roadmap
Implement WordPress + WooCommerce, real product data and inventory, taxes and shipping rules, secure payment gateway, account/customer flows, privacy policy, accessibility audit, image licensing, analytics, SEO, and cross-browser QA.
